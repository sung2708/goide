# Goro 0.5.0-alpha.2

This experimental prerelease replaces CodeMirror with Monaco. The existing Goro
palettes, document safety and Go tooling workflows are retained.

## Changes

- Per-file Monaco models preserve undo history and view state across tabs.
- Completion follows exact unsaved buffers, refreshes as prefixes grow and stays
  active in snippet placeholders. Stale requests cannot overwrite current results.
- Autosave writes drafts without waiting for formatting. Explicit Save preserves
  incomplete Go when gopls reports a parser error; Run still flushes pending saves.
- Local syntax errors appear on their source rows. Operational failures appear in
  the status bar and Problems dock instead of covering the editor.
- Optional Vim motions, context mappings and Insert-mode preferences are available
  in Settings. Markdown rows render sanitized previews and expose source on hover
  or selection.
- Settings use switches; controls have restrained hover, press and focus feedback.
  Goro Dark/Light retain the existing stored theme IDs and palettes.
- Windows start centered at 1200 × 720 without maximizing.

## Acceptance and limits

The maintainer reported successful manual testing of the dev application on
2026-10-05. Source CI and package verification must pass for the final release
commit before publication; this document is preparation, not proof of publication.

Clean-machine installation, signed upgrades, complete native interaction coverage,
IME/accessibility and measured editor performance remain open. Complex Markdown
layouts and Unix descendant containment also need further acceptance. This alpha
does not establish beta or production readiness.
