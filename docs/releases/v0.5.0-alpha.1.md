# Goro 0.5.0-alpha.1

An experimental desktop IDE for Go, released from main after develop promotion.
This alpha includes the current Go editing, project, toolchain and document-safety
work. It is for evaluation; it does not establish beta or production readiness.

## Included

- Go syntax highlighting, completion, hover, diagnostics, definitions/references,
  signature help, reviewed rename/format/imports and supported gopls code actions.
- Multiple document tabs, guarded Save/Don't Save/Cancel transitions, external-file
  conflict handling, export copies and optional bounded local draft checkpoints.
- Open, create and close projects from the persistent Project menu. The menu closes
  on outside presses. New Go projects initialize their module; dependency commands
  remain explicit. Reopened workspaces restore the saved active tab without cycling
  through background tabs.
- Optional managed installation of pinned Go, gopls and Delve through Go Toolchain.
  Downloads require network access; installation and activation are separate.
  Existing/custom tool paths remain supported. Git is installed separately.
- Quick Open, command palette, in-file and workspace search/replace with preview,
  source Back/Forward, themes and editor/tool settings.
- Run and structured Go tests, Delve debugging with breakpoints, stepping, stacks
  and variables, and an integrated terminal.
- Git changes/staging, diffs, commits, branches, history/graph, stashes and conflict
  review with operation-bound cancellation.
- Signed updater manifests and checksummed downloads for Windows x64, macOS ARM64,
  macOS Intel x64 and Linux x64. Configured packages are not platform certification.

## Limits to consider before testing

- Clean-machine installation, upgrade/uninstall, platform publisher trust and
  complete native interaction acceptance remain unverified across the full matrix.
  Updater signatures do not establish Authenticode or Apple notarization.
- Unix terminal descendant containment and shutdown/recovery acceptance remain
  open. Do not assume every descendant is stopped on Unix.
- Local draft checkpoints are bounded and delayed; they do not guarantee recovery
  of the last keystroke after a crash or power loss. Back up important workspaces.
- Installed-app typing/scroll/completion latency, IME and accessibility measurements
  remain open. Source regression tests are not native performance measurements.
- Managed tools are downloaded on demand, not bundled as an offline installer.
  Projects can still require dependencies, platform compilers or debugging permission.
- Concurrency/race views are experimental; sampled goroutines are not a complete
  causality trace. Advanced Git and semantic navigation acceptance remains open.
