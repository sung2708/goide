# Goro 0.2.0-alpha.1

An experimental desktop IDE for Go. This release is built from main and uses your locally installed Go, gopls, Delve and Git. It is an alpha for evaluation; native preservation, packaging and platform acceptance are still incomplete.

## Included

- Go editor with syntax highlighting, completion, hover, diagnostics, signature help and supported gopls edits. Review applicable workspace edits before applying them.
- File navigation, command palette, in-file and workspace search/replace with replacement preview. Workspace search reads files on disk.
- Run and test with Go; debug with Delve breakpoints, stepping, variables and call stacks.
- Source Control and Git Graph, including diffs, commit history, branches, stashes and conflict handling. Cancellation targets a specific operation and remains bound to its original workspace.
- Interactive terminal, editor/tool settings and twelve color palettes.
- Experimental sampled goroutine inspection and Go race-report views. Samples do not establish a complete causality trace.
- Signed updater support, channel selection and explicit installation consent. Download links, checksums and update manifests are generated from the same verified artifacts.
- Dependency security patches and automated npm/Rust advisory checks.

## Known limitations

- Native UI journeys for external-file conflicts, failed saves, dirty close/Explorer/Git transitions and active-process shutdown have not completed acceptance. Local Computer Use capture/input was unavailable.
- Unix PTY descendant/session containment remains incomplete. Do not assume every descendant is stopped on Unix.
- Clean-machine install/upgrade/uninstall, platform publisher trust, editor latency and IME/accessibility acceptance remain unverified. Updater signatures verify update integrity; they do not provide Windows Authenticode or macOS notarization.
- Save As/export-copy and crash recovery of unsaved drafts are not implemented. View/session restoration does not preserve unsaved text after a crash. Back up work and save regularly.
- Workspace search does not include unsaved buffers. Sampled runtime views are experimental.
- Debian packages require manual updates; automatic Linux updates apply to AppImage installations. Windows/Linux ARM are not included.

## Verification and prerequisites

Local Windows verification passed 798 frontend tests and 286 native tests, including 24 tests with Go 1.26.5, gopls 0.23.0, Delve 1.27.2 and Git 2.54.0.windows.1. These results do not certify other platforms or manual native journeys. The release workflow runs its own deterministic checks and signs/verifies the complete artifact matrix before publication.

Install the Go toolchain, gopls, Delve and Git separately. Keep this alpha's limitations in mind when choosing a workspace. The full QA evidence and outstanding gates remain in docs/QA_HARDENING_FOLLOWUP.md and docs/RELEASE_READINESS.md.
